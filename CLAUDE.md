# Neiry — сайт neiry-bci.ru

Статичный одностраничный сайт: всё в `index.html`. Публикуется через GitHub Pages из ветки `main` (домен в `CNAME`).

## Правила работы

- Никогда не пушить в `main` напрямую. Любые изменения — в отдельной ветке и через Pull Request.
- Мёрдж PR в `main` делает человек после просмотра, не Claude.
